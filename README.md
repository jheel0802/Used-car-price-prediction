# Used-car-price-prediction
The prices of new cars are on the rise. As a result, people are more inclined towards buying used cars. However, the sellers as well as the buyers have no idea, what should be the price of those used cars. This is where we come in. Our web app helps to find out the price of used cars based on car information and provide the estimated price of that car at that point of time. An end-to-end machine learning project for estimating used-car prices from vehicle attributes such as manufacturer, model, year, mileage, fuel type, and other specifications.

## Overview

Used-car pricing depends on a combination of vehicle age, usage, manufacturer, model, and technical characteristics. This project builds a machine learning pipeline to preprocess vehicle data and predict a vehicle's market price from these attributes.

The project covers the complete workflow from **data cleaning and feature engineering to model training and a web-based prediction interface**.

## Tech Stack

- Python
- Pandas
- NumPy
- scikit-learn
- Jupyter Notebook
- HTML/CSS
- Machine Learning / Regression

## Pipeline

1. Clean and preprocess raw vehicle data
2. Handle missing and inconsistent values
3. Engineer relevant vehicle features
4. Prepare categorical and numerical features for modeling
5. Train and evaluate regression models
6. Save the trained model for inference
7. Use the model through a web-based interface
